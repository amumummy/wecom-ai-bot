# 部署步骤（阿里云 <你的服务器IP>）

## 0. 前置检查（SSH 到服务器执行）

```bash
# 确认 8080 端口空闲（Grafana 3000 / HAE-server 3001 已占用，互不影响）
ss -tlnp | grep 8080 || echo "8080 空闲"

# 确认 Java 环境（无则装：yum install -y java-1.8.0-openjdk 或 apt install openjdk-11-jre-headless）
java -version
```

阿里云控制台 → 安全组：确认入方向已放行 **8080**（TCP，0.0.0.0/0 或限企微回调 IP 段）。

## 1. 上传部署包

本机执行：
```bash
scp wecom-ai-bot-deploy.zip root@<你的服务器IP>:/opt/
ssh root@<你的服务器IP> "cd /opt && unzip wecom-ai-bot-deploy.zip && cd wecom-ai-bot-deploy && chmod +x start.sh"
```

## 2. 填密钥

```bash
cp env.example.sh env.sh
vim env.sh   # 填入 Token / EncodingAESKey（企微后台回调配置页拿的）+ 应用 Secret
```

## 3. 启动

```bash
./start.sh
tail -f bot.log   # 看到 "WXBizMsgCrypt initialized" 和 Tomcat started on port 8080 即成功
```

## 4. 冒烟测试（选做）

```bash
curl "http://127.0.0.1:8080/wecom/callback"   # 返回 400 说明服务在监听（缺参数报错属正常）
```

## 5. 回企微后台点保存（关键一步）

应用详情 → 接收消息 → 设置API接收 → URL/Token/EncodingAESKey 都已填好 → 点「保存」。
企微立刻发 GET 验证 → 服务器日志出现 `[URL验证] 通过` → 页面提示保存成功 ✅

**阶段A验收通过。**
